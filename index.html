N°01LAUNCHLAB WORKSHOP

From Design
to Deployment

PRESENTED BY Yibo · Nirvan · Rishabh

LaunchLab was a hands-on workshop on moving from a website idea to a working, published website — using AI-assisted tools to design, build, store and deploy it.

THE WORKFLOW

Design→Build→Store & Version→Deploy

CLAUDE DESIGNCLAUDE CODEGITHUBVERCEL

KEY Learnings

(05)
  1. 01

    Design

    CLAUDE DESIGN

    Claude Design helps shape the website's visual interface and overall user experience — deciding how the site should look before it is built.

  2. 02

    Build

    CLAUDE CODE

    Claude Code is used to turn the design into a working website, by handing off the design made in Claude Design.

  3. 03

    Store & Version

    GITHUB

    GitHub stores the project files and tracks changes to the code.

  4. 04

    Deploy

    VERCEL

    Vercel publishes the website so people can access it online.

  5. 05

    Backend Foundations

    SUPABASE

    Supabase was introduced in the workshop as a backend tool — the part of a website that works behind its visible interface.

You have the tools. Can you put the workflow together?
